# Armanium comments

This public repository stores GitHub Discussions used by the comment sections on [blog.armanium.com](https://blog.armanium.com).

Comments are powered by [Giscus](https://giscus.app). A GitHub account is required to participate.

## Moderation

Comments may be removed when they contain spam, harassment, impersonation, doxxing, private information, or security-sensitive material. Keep discussion relevant to the associated article and treat other participants respectfully.

The blog's source code remains in a separate private repository. This repository contains public discussions only.
